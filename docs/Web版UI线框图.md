# Web 版 UI 线框图

这份文件用等宽字符画出 [`web/index.html`](../web/index.html) 与
[`web/style.css`](../web/style.css) 的**结构**：各标签页有哪些区域、左右两栏怎么分、
窗口变窄之后怎么折叠。它**不追求像素级还原**——颜色、圆角、间距、字号一律以 CSS 为准。

读法：

* 每张图按 **80 列** 宽排版（等宽字体，中文占 2 列），左栏 44 列 + 间隔 + 右栏 34 列；
* `[ ]` / `[x]` 是复选框，`[ 按钮 ]` 是按钮，`[… ▾]` 是下拉框，`[ 文本 ]` 是输入框；
* `┄` 虚线框 = 拖放区（拖到上方时边框变强调色）；
* 标签页用方括号标出当前项，例如 `[导出贴图]`。
* 控件外观来自 Bootstrap（[`web/vendor/bootstrap.min.css`](../web/vendor/bootstrap.min.css)）；
  [`web/style.css`](../web/style.css) 只写配色覆盖与站点自有组件。

（`position: sticky; bottom: 0`）。

## 2. 标签页 1：导出贴图（`#tab-export`）

一张卡片装全部内容：输入行、动作行、结果区。没有导出按钮，结果随输入与选项自动重画（WUI-24）。
没有导出目标可勾选：三个页签的内容总齐全（WUI-22）。历史不占版面，它藏在拖放区右上角的时钟图标背后（WUI-23）。

```text
┌（无标题）──────────────────────────────────────────────────────────────────┐
│ ┌┄┄┄┄┄┄┄┄┐ ┌───────────────┐                                                   │
│ ┆ 拖入/上传 ┆ ┆[动画] [▶]     ┆                                                   │
│ ┆ 绘制模板  ┆ ┆20 帧 [❙◀]     ┆                                                   │
│ ┆[🗑][◫][◷][⤓]┆ ┆ 5/52 [▶❙]     ┆                                                   │
│ ┆          ┆ ┆ ☐女☐玩家ⓘ     ┆                                                   │
│ ┆          ┆ ┆ [速率▾]        ┆                                                   │
│ ┆          ┆ ┆ [尺寸▾]        ┆                                                   │
│ └┄┄┄┄┄┄┄┄┘ └───────────────┘                                                   │
│ [ 上传 ]   [ 来个 Demo ]                                                          │
│                                                                                   │
│ 材质包卡片：标题 → 操作行 → [1.4] [1.3] [全身盔甲] → 文件表 + 贴图列              │
│ 文件表：文件名 · 尺寸 · ID（数字输入 + 原版名称）· 说明                          │
└───────────────────────────────────────────────────────────────────────────────┘
```

* 卡片没有标题；拖放区按模板自身比例 128:80 且靠左，载入后把虚线框填满，虚线变实线。
* 拖放区文字固定两行：`拖入/上传 绘制模板` 与 `支持 .png 和 .webp 格式`。
* 拖放区右侧是与它等高的矩形框，宽度固定 `12.5rem`，默认隐藏：没有模板时不出现，
  清空拖放区后再次隐藏。框内上方是 20 帧动画，动画右侧竖排三个图标按钮：播放 / 暂停、
  上一帧、下一帧，按钮下方是「当前帧/总帧数」。下方是「女性版本 / 叠加玩家 / 提问图标」
  与 `GIF 速率` `GIF 尺寸` 两个下拉，下拉竖排、宽度固定 `11.2rem`，尺寸小于 `form-select-sm`。
  这两个下拉与预览贴图页的同名设置互不影响。
* 动画画在 `canvas` 上而不是播放 GIF：`<img>` 里的 GIF 停不到指定帧。帧号按导出 GIF 的
  帧序列计（52 帧，含停顿与重复帧）。默认播放；按上一帧或下一帧时自动暂停。
* 拖放区右上角四个图标，自上而下：`[🗑]` 清空、`[◫]` 参考线、`[◷]` 最近导出、`[⤓]` 下载。
  四个图标同一套线宽与圆头，只在鼠标移入时整组淡入，因此不再压暗。
  前三个都阻止冒泡，点图标不会打开文件选择；没有模板时下载与清空禁用。
  参考线按钮用 `aria-pressed` 与高亮表示状态，写 `state.config.guide`；盔甲模板页的复选框是另一份设置。
  下载按钮给的是当前画面：参考线开着就下载合并后的图，关着就是原图。
  Demo 模板自带标注，载入后参考线图标直接隐藏，预览与下载都按原图处理。
* `[来个 Demo]` 载入内置绘制模板 `data/ArmorTemplate_v1.png`，走与拖放相同的校验流程。
* 图标按钮没有文字，提示走样式化 tooltip（`data-tooltip` + CSS），不是 `title`。
* 结果区 `#results` 在同一张卡里，空着时不写占位文字：拖放区自己已经说明了该做什么。
* 没有文件行与摘要行：拖放区直接显示模板本身（WUI-18）。

## 3. 标签页 2：预览贴图（`#tab-gifs`）

整页只有一张卡，自上而下依次是：拖拽区、选项、按钮、结果。先放贴图，再调参数，
动作按钮放在参数下面、结果上面。
拖拽区是 `grid` 三列，宽度固定 `180px 360px 180px`，高度都是 `224px`：身体那一格正好是
贴图的 `360×224`，像素 1:1；头部与腿部各是身体的一半宽。
槽位标题只有「头」「身体」「腿」；拖拽区文字固定两行，第二行是原版文件名示例与尺寸。
放入后整张显示贴图，文件名与尺寸分两行写在格子下方；右上角是 × 图标按钮，头部与腿部的
× 下面还有左右箭头，可以把两格互换；格子左上角显示 ✓。
状态行只写警告，不再逐个列 ✓，也不再写还缺哪个部位。
没有「生成预览」按钮：三张贴图与两个下拉就是全部输入，任何一项变化都重画卡片。
`[ 下载材质包 ]` 默认隐藏，只有三个槽位都填上才出现并可用。

```text
┌ 三张成品贴图 → 全身预览 ─────────────────────────────────────────────────────┐
│                                                                              │
│ 头                    │ 身体                        │ 腿        ×          │
│ (180×224)         ×   │ (360×224)               ×   │ (180×224)              │
│ ┌ 拖入 / 上传 png图片 ┐│ ┌ 拖入 / 上传 png图片 ────┐│ ┌ 拖入 / 上传 png图片┐│
│ │ Armor_Head_0.png   ││ │ Armor_0.png            ││ │ Armor_Legs_0.png   ││
│ │ · 40×1120          ││ │ · 360×224(整数倍也行)  ││ │ · 40×1120          ││
│ └────────────────────┘│ └────────────────────────┘│ └────────────────────┘│
│ Armor_Head_0.png · 40×1120 …（文件名与尺寸分两行写在格子下方）                │
│                                                                              │
│ GIF 速率 [快 100ms]   GIF 尺寸 [原始]   [ ] 叠加玩家 (i)                       │
│ [ 上传 ] [ 来个 Demo ]                                                        │
│                                                                              │
│ 三张齐了才有「下载材质包」与导出结果                                          │

下方是一张「操作说明」卡片，四行编号说明。
```

「下载材质包」把三张贴图打成游戏可直接读的 `<名称>-pack-pc.zip`
（`pack.json` + `Content/Images/…`），结果落在卡片最后，可以直接下载或写进 `ResourcePacks`。

## 4. 标签页 3：盔甲模板（`#tab-reverse`）

左卡 `col-lg-6`，右卡 `col-lg-6`，栅格撑满。套装列表是 `<select size="8">`，
所以本身就是 8 行高的可滚动框。选中条目即填入三个 ID 并立即还原，改动任一 ID 也立即还原，
因此本页没有「还原这一套」按钮。

左卡字段顺序：搜索、套装列表、分隔线、贴图来源、叠加标准图 + GIF 速率、操作按钮。
三个部件 ID 与每个 ID 下方的部件名称在右卡第一行；套装名在它们上方，字号比正文大一档。

```text
┌ 盔甲模板 ──────────────────────────────┐  ┌ 预览 ────────────────────────────┐
│ 搜索套装   [ 星尘                 ]    │  │ 铜链甲                           │
│                                        │  │ 头部[1]      身体[1]      腿部[1]│

│  星尘板甲 StardustPlate(189,190,130)   │  │ 身体 ID 必填；头/腿留空时按套装表 │

│                                        │  │ 生成效果 (20 帧)   GIF 动画 2X   │
```

`#set-select` 用原生 `<select>`，条目文本右端是三个 ID 与缺件标记 ⚠。

本页写 `state.config.revGuide`，两者互不影响。

## 6. 响应式

布局用 Bootstrap 5.3 的栅格（`row` / `col-lg-*`）。

### `max-width: 991.98px`

`col-lg-*` 失去并排效果，两侧改为**竖排**（盔甲模板页的输入卡与预览卡各占整宽）。
导出页与预览贴图页本来就是单卡，只变窄。

## 7. 状态与交互

| 区域 | 状态 | 表现 |
|---|---|---|
| 标签页 | `.tab.active` | 文字加粗 + 下划线（`nav-underline`），不用填充按钮 |
| 拖放区 | `:hover` / `:focus` / `.is-over` / `.is-filled` | 虚线边框变 `--accent`，底色加深；载入模板后虚线变实线并显示模板本身 |
| 历史浮层 | `#history-pop` 未 `hidden` | 时钟按钮下方弹出，`aria-expanded` 跟著变 |
| 槽位 | 已放入贴图 | 整张贴图填满格子 + 左上角 ✓；格子下方分两行写文件名与尺寸；右上角出现 × 按钮，头部与腿部在 × 下方再多一个交换按钮；`[ 下载材质包 ]` 解禁；三个槽位齐了卡片自动重画 |
| 状态栏 | `.ok` / `.warn` / `.bad` / `.busy` | 绿 / 黄 / 红 / 蓝四色文字 |
| 任务中 | `#job-bar` + `[ 取消 ]` | 进度条（160px）与取消按钮从 `hidden` 显示 |
| 结果卡 | 生成后 | 预览图 + 文件名与 `宽×高px` + 单张下载 + zip；悬停链接浮出该图 |
