# Web 版 UI 线框图

这份文件用等宽字符画出 [`web/index.html`](../web/index.html) 与
[`web/style.css`](../web/style.css) 的**结构**：各标签页有哪些区域、左右两栏怎么分、
窗口变窄之后怎么折叠。它**不追求像素级还原**——颜色、圆角、间距、字号一律以 CSS 为准。

读法：

* 每张图按 **80 列** 宽排版（等宽字体，中文占 2 列），左栏 44 列 + 间隔 + 右栏 34 列；
* `[ ]` / `[x]` 是复选框，`[ 按钮 ]` 是按钮，`[… ▾]` 是下拉框，`[ 文本 ]` 是输入框；
* `┄` 虚线框 = 拖放区（拖到上方时边框变强调色）；
* 标签页用方括号标出当前项，例如 `[拆图]`。
* 控件外观来自 Bootstrap（[`web/vendor/bootstrap.min.css`](../web/vendor/bootstrap.min.css)）；
  [`web/style.css`](../web/style.css) 只写配色覆盖与站点自有组件。

## 2. 标签页 1：拆图（`#tab-export`）

一张卡片装全部内容：输入行、动作行、结果区。没有导出按钮，结果随输入与选项自动重画（WUI-24）。
页签只留两个时代：1.4 与 1.3。全身帧与 GIF 由右侧播放器负责，所以不再有「全身盔甲」页签。
历史不占版面，它藏在拖放区右上角的时钟图标背后（WUI-23）。

```text
┌（无标题）──────────────────────────────────────────────────────────────────┐
│ ┌┄┄┄┄┄┄┄┄┐ ┌── 动画 ──┐ ┌ 选项 ────────┐                                       │
│ ┆ 拖入/上传 ┆ │         │ │ ☐ 女版        │                                       │
│ ┆ 绘制模板  ┆ │  20 帧  │ │ ☐ 叠加玩家 ⓘ  │                                       │
│ ┆[🗑][◫][◷][⤓]┆ │         │ │ [速率 ▾]      │                                       │
│ ┆          ┆ │         │ │ [尺寸 ▾]      │                                       │
│ ┆          ┆ └─────────┘ │ [▶][❙◀][▶❙] 5/52│                                       │
│ └┄┄┄┄┄┄┄┄┘             │ ────────────── │                                       │
│                        │ FullArmor.png ⓘ │                                       │
│                        └──────────────┘                                       │
│ [ 上传 ]   [ 来个 Demo ]                                                          │
│                                                                                   │
│ 材质包卡片：标题 → 操作行 → [1.4] [1.3] → 文件表 + 贴图列                        │
│ 文件表：文件名 · 尺寸 · ID（数字输入 + 原版名称）· 说明                          │
└───────────────────────────────────────────────────────────────────────────────┘
```

* 卡片没有标题；拖放区按模板自身比例 128:80 且靠左，载入后把虚线框填满，虚线变实线。
* 拖放区文字固定两行：`拖入/上传 绘制模板` 与 `支持 .png 和 .webp 格式`。
* 拖放区右侧是播放器，默认隐藏：没有模板时不出现，清空拖放区后再次隐藏。播放器分两栏：
  左栏画面区宽度固定 `168px`（正好放得下 4× 的 160×224），1× 与 2× 的帧在其中居中；
  右栏一行一个控件，依次是 `女版`、`叠加玩家 ⓘ`、`GIF 速率`、`GIF 尺寸`，
  最后一行是播放 / 暂停、上一帧、下一帧与「当前帧/总帧数」，写在尺寸下拉的下面。
  再下面一条分隔线，然后是当前画面的 PNG 下载链接（`FullArmor.png` 等，去掉 id 前缀）
  与紧挨着的 ⓘ 图标，悬停显示「全身盔甲，20 帧。GIF 预览 52 帧。」。
  画面区高度按 4× 固定，切换尺寸时卡片高度不变。
  这两个下拉与预览页的同名设置互不影响。
* 动画画在 `canvas` 上而不是播放 GIF：`<img>` 里的 GIF 停不到指定帧。帧号按导出 GIF 的
  帧序列计（52 帧，含停顿与重复帧）。默认播放；按上一帧或下一帧时自动暂停。
* 拖放区右上角四个图标，自上而下：`[🗑]` 清空、`[◫]` 参考线、`[◷]` 最近导出、`[⤓]` 下载。
  四个图标同一套线宽与圆头，只在鼠标移入时整组淡入，因此不再压暗。
  前三个都阻止冒泡，点图标不会打开文件选择；没有模板时下载与清空禁用。
  参考线按钮用 `aria-pressed` 与高亮表示状态，写 `state.config.guide`；模板页的复选框是另一份设置。
  下载按钮给的是当前画面：参考线开着就下载合并后的图，关着就是原图。
  Demo 模板自带标注，载入后参考线图标直接隐藏，预览与下载都按原图处理。
* `[来个 Demo]` 载入内置绘制模板 `data/ArmorTemplate_v1.png`，走与拖放相同的校验流程。
* 图标按钮没有文字，提示走样式化 tooltip（`data-tooltip` + CSS），不是 `title`。
* 结果区 `#results` 在同一张卡里，空着时不写占位文字：拖放区自己已经说明了该做什么。
* 没有文件行与摘要行：拖放区直接显示模板本身（WUI-18）。

## 3. 标签页 2：预览（`#tab-gifs`）

一张卡片分左右两半：左半边放三张贴图与按钮，右半边是 20 帧播放器。
宽度不够时右半落到左半的下一行，左半边永远按内容取宽，不被压缩。

左半边的槽位是 `grid` 三列，宽度 `90px 360px 90px`，列间距 `8px`，高度都是 `224px`：
身体那一格正好是贴图的 `360×224`；头部与腿部各是身体的一半宽。
头部与腿部的贴图按 1:1 显示，条带比格子高，所以格子内滚动，滚动条只在悬停或滚动时出现。
槽位标题写在格子下方、左对齐，旁边是 ⓘ 图标，悬停显示「文件名 / 宽×高」。
放入后整张贴图填满格子，右上角是 × 图标按钮，头部与腿部的 × 下面还有左右箭头，可以互换两格；
格子左上角显示 ✓。
状态行只写警告；`[ 下载材质包 ]` 默认隐藏，三个槽位都填上才出现。

右半边自上而下：播放器、材质包名称 / 作者 / 备注三个输入框。播放器与「拆图」页共用一套样式：
画面区宽度固定 `168px`，右栏一行一个控件（`女版`、`叠加玩家 ⓘ`、`GIF 速率`、`GIF 尺寸`），
最后一行是播放 / 暂停、上一帧、下一帧与帧数，写在尺寸下拉的下面；下方一条分隔线，
再下面是当前预览的 PNG 下载链接，紧挨着一个 ⓘ 图标，悬停显示「全身盔甲，20 帧。GIF 预览 52 帧。」
画面区高度按 4× 固定，切换尺寸时卡片高度不变。

本页**没有结果区**：播放器给出动画，链接给出 PNG，所以不再有拼版预览、GIF 预览与文件表。

## 4. 标签页 3：模板（`#tab-reverse`）

左卡 `col-lg-6`，右卡 `col-lg-6`，栅格撑满。套装列表是 `<select size="8">`，
所以本身就是 8 行高的可滚动框。选中条目即填入三个 ID 并立即还原，改动任一 ID 也立即还原，
因此本页没有「还原这一套」按钮。

左卡字段顺序：搜索、套装列表、分隔线、贴图来源、Wiki 文字链接、叠加标准图 + GIF 速率、操作按钮。

拆图页与预览页本来就是单卡，只变窄。

## 7. 状态与交互

| 区域 | 状态 | 表现 |
|---|---|---|
| 标签页 | `.tab.active` | 文字加粗 + 下划线（`nav-underline`），不用填充按钮 |
| 拖放区 | `:hover` / `:focus` / `.is-over` / `.is-filled` | 虚线边框变 `--accent`，底色加深；载入模板后虚线变实线并显示模板本身 |
| 历史浮层 | `#history-pop` 未 `hidden` | 时钟按钮下方弹出，`aria-expanded` 跟著变 |
| 槽位 | 已放入贴图 | 整张贴图填满格子 + 左上角 ✓；标题在格子下方、左对齐，旁边的 ⓘ 悬停显示文件名与尺寸；右上角出现 × 按钮，头部与腿部在 × 下方再多一个交换按钮；`[ 下载材质包 ]` 解禁；三个槽位齐了播放器自动播放 |
| 状态栏 | `.ok` / `.warn` / `.bad` / `.busy` | 绿 / 黄 / 红 / 蓝四色文字 |
| 任务中 | `#job-bar` + `[ 取消 ]` | 进度条（160px）与取消按钮从 `hidden` 显示 |
| 结果块 | 生成后 | 预览图 + 文件名与 `宽×高px` + 单张下载 + zip；悬停链接浮出该图 |
| 播放器 | 有帧时 | 画面区高度按 4× 固定；播放中按钮显示暂停图标，单帧步进时自动暂停 |
