# Web 版 UI 线框图

这份文件用等宽字符画出 [`web/index.html`](../web/index.html) 与
[`web/style.css`](../web/style.css) 的**结构**：各标签页有哪些区域、左右两栏怎么分、
窗口变窄之后怎么折叠。它**不追求像素级还原**——颜色、圆角、间距、字号一律以 CSS 为准。

读法：

* 每张图按 **80 列** 宽排版（等宽字体，中文占 2 列），左栏 44 列 + 间隔 + 右栏 34 列；
* `[ ]` / `[x]` 是复选框，`[ 按钮 ]` 是按钮，`[… ▾]` 是下拉框，`[ 文本 ]` 是输入框；
* `┄` 虚线框 = 拖放区（拖到上方时边框变强调色）；
* 标签页用方括号标出当前项，例如 `[导出贴图]`。

## 1. 整体骨架

页头 + 主区 + 吸底状态栏。页头在窄屏会换行（`flex-wrap`），状态栏始终贴在窗口底部
（`position: sticky; bottom: 0`）。

```text
┌──────────────────────────────────────────────────────────────────────────────┐
│                                                                              │
│ [#]  ArmorHelper            [导出贴图] 预览贴图 反向还原 设置      中文 ▾    │
│      泰拉盔甲贴图 · 纯前端 · 可离线                                          │
│                                                                              │
├ 主区 main（.panel.is-active 的内容，四个标签页之一） ────────────────────────┤
│                                                                              │
│                         … 见第 2 ~ 5 节 …                                    │
│                                                                              │
├ 状态栏 .statusbar（sticky bottom，常驻） ────────────────────────────────────┤
│ 就绪 · 纯前端，全部在本机处理  [######....] 3/8           [ 取消 ]           │
└──────────────────────────────────────────────────────────────────────────────┘
```

## 2. 标签页 1：导出贴图（`#tab-export`）

左栏是「输入 → 结果 → 历史」三张卡纵向排；右栏是一张**吸顶的常驻侧栏**
（`position: sticky; top: 16px`，高 `calc(100vh - 32px)`，内部滚动），
所以结果长得再高，「开始导出」也不会被挤出视野。侧栏固定 320px，左栏吃掉剩下的宽度。

## 3. 标签页 2：预览贴图（`#tab-gifs`）

三个槽位是 `grid` 三等分（`repeat(3, minmax(0, 1fr))`），标题里直接写清原版命名与尺寸；
放入后槽位里显示缩略图（40×1120 的长图显示首帧 2×，身体 9×4 显示整张）。右栏比导出页窄
（`#tab-gifs .sidebar` 是 `min(520px, 45%)`），因为要放 40×56 的 GIF。
`[ 生成预览 ]` / `[ 生成材质包 ]` 在三个槽位都填上之前是 `disabled`。

```text
┌ 三张成品贴图 → 全身预览 ───────────────┐  ┌ 导出结果 ────────────────────────┐

│ 头部（Armor_Head_ · 40×1120px） [移除] │  │                                  │
│ ┌──────── 缩略图 + 文件名 尺寸 ───────┐ │  │ 每张 GIF 一张卡：                │
│ 身体（Armor_ · 360×224，整数倍也行）   │  │ ┌──────────────────────────┐     │
│ ┌──────── 整张 9×4 网格 ─────────────┐ │  │ │  全身盔甲（男） 2× 40×56 │     │
│ 腿部（Armor_Legs_ · 40×1120px） [移除] │  │ └──────────────────────────┘     │
│ ┌──────── 首帧 2× ───────────────────┐ │  │ ┌──────────────────────────┐     │
│ 未选择任何贴图                         │  │ │  全身盔甲（女） 2× 40×56 │     │
```

「生成材质包」把三张贴图打成游戏可直接读的 `<名称>-pack-pc.zip`
（`pack.json` + `Content/Images/…`），结果会出现在右卡里，可以直接下载或写进 `ResourcePacks`。

## 4. 标签页 3：反向还原（`#tab-reverse`）

这里用的是 `.row` 而不是 `.split`：左卡 `flex: 1 1 420px`（`grow`），右卡 `flex: 0 1 330px`，
两栏等高拉伸。套装列表是 `<select size="8">`，所以本身就是 8 行高的可滚动框。

## 6. 响应式

### `max-width: 900px`

`.split` / `.row` 从左右两栏改为**竖排**（导出页的输入卡与结果卡各占整宽）；
`.sidebar` 失去 `sticky`，变成普通整宽卡片。

```text
┌──────────────────────────────────────────────────────────────────────────────┐
│                                                                              │
│ [#] ArmorHelper                          中文 ▾                              │
│ [导出贴图] [预览贴图] [反向还原] [设置]                                      │
│                                                                              │
├ 输入文件 ────────────────────────────────────────────────────────────────────┤
│ …                                                                            │
│                                                                              │
├ 导出结果 ────────────────────────────────────────────────────────────────────┤
│ …                                                                            │
│                                                                              │
├ 最近导出 ────────────────────────────────────────────────────────────────────┤
│ …                                                                            │
│                                                                              │
└──────────────────────────────────────────────────────────────────────────────┘
```

### `max-width: 700px`

`.slots` 的三列变一列，头部 / 身体 / 腿部槽位竖着堆（下图里的 `[ … ]` 是一整行的拖放框，
不是按钮）：

```text

│                                                                              │
│ 头部   [ 拖到这里，或点击选择 ]                                              │
│                                                                              │
│ 身体   [ 拖到这里，或点击选择 ]                                              │
│                                                                              │
│ 腿部   [ 拖到这里，或点击选择 ]                                              │
```

## 7. 状态与交互

| 区域 | 状态 | 表现 |
|---|---|---|
| 标签页 | `.tab.is-active` | 底色 `--panel-2` + 边框，其余为 `--muted` 文字 |
| 拖放区 | `:hover` / `:focus` / `.is-over` | 虚线边框变 `--accent`，底色加深 |
| 槽位 | 已放入贴图 | 显示缩略图（40×1120 显示首帧 2×）+ 文件名与尺寸，右上角出现「移除」，`[ 生成预览 ]` / `[ 生成材质包 ]` 解禁 |
| 状态栏 | `.ok` / `.warn` / `.bad` / `.busy` | 绿 / 黄 / 红 / 蓝四色文字 |
| 任务中 | `#job-bar` + `[ 取消 ]` | 进度条（160px）与取消按钮从 `hidden` 显示 |
| 结果卡 | 生成后 | 预览图 + 尺寸 + 单张下载 + zip + 写入输出目录 |

## 8. 线框 ↔ DOM 对照

| 线框里的区域 | DOM |
|---|---|
| 页头 / 标志 / 标签页 / 语言 | `header.topbar` → `.brand`、`nav.tabs`、`.lang` |
| 主区四个标签页 | `section.panel#tab-export` / `#tab-gifs` / `#tab-reverse` / `#tab-settings` |
| 导出：拖放区 + 文件列表 | `#drop`、`#file-input`、`#file-summary`、`#file-list` |
| 导出：结果 / 历史 | `#results`、`#history-list`、`#clear-history` |
| 导出：目标清单 / 预览选项 / 主按钮 | `#targets`、`#opt-female`、`#opt-player`、`#opt-guide`、`#do-export` |
| 预览贴图：三个槽位 | `#sheet-head-slot`、`#sheet-body-slot`、`#sheet-legs-slot`（各带 `*-input`、`*-clear`） |
| 预览贴图：选项与结果 | `#gif-speed`、`#gif-size`、`#gif-player`、`#do-gifs`、`#do-pack`、`#gif-results` |
| 反向还原：来源与套装 | `#pick-images`、`#pick-textures`、`#texture-input`、`#set-search`、`#set-select` |
| 反向还原：ID 与动作 | `#rev-head`、`#rev-body`、`#rev-legs`、`#do-reverse`、`#do-reverse-all`、`#reverse-result` |
| 设置 | `#pick-output`、`#clear-output`、`#pick-images-2`、`#set-head`…`#set-skin`、`#set-glow`、`#set-verify`、`#save-settings`、`#about` |
| 状态栏 | `footer.statusbar` → `#status`、`#job-bar`、`#cancel-job` |
