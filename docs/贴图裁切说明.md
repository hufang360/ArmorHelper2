# 原版盔甲贴图裁切说明

以 1.4.5 的**铜盔甲**（`Armor_1` / `Armor_Head_1` / `Armor_Legs_1`）为例，说明三张贴图分别
怎么切、每一刀对应游戏里的什么。

> | 文件 | 位置 | 尺寸 |
> |---|---|---|
> | `Armor_Head_1.png` | `Content/Images/` 根目录 | 40 × 1120 |
> | `Armor_Legs_1.png` | `Content/Images/` 根目录 | 40 × 1120 |
> | `Armor_1.png` | `Content/Images/Armor/` 子目录 | 360 × 224 |

---

## 0. 三条通用约定

1. **所有原版盔甲贴图都是 1× 像素画的精确 2 倍最近邻放大**（实测 748 个文件里，
   2×2 同色块比例 100%，只有 22 个文件有 0.005%~0.18% 的零星例外）。想拿 1× 素材，
   把尺寸除以 2 再用最近邻取样即可。
2. **一格 = 40 × 56 像素**，也就是逻辑上的 20 × 28。
3. **PIL 的 `crop` 参数是 `(left, upper, right, lower)`，不是 `(x, y, w, h)`**。
   下文表格里的「裁切框」给的就是可以直接丢给 `crop()` 的四个数。

## 1. `Armor_1.png` —— 身体 + 双臂（360 × 224）

### 1.1 整体结构

**9 列 × 4 行**，共 36 格，每格 40 × 56。发光盔甲（如星尘 190）是 **9 列 × 8 行**
（360 × 448），第 4~7 行是发光遮罩，引擎采样时做 `sourceRect.Y += 224`。

```
x  →    0    40   80   120  160  200  240  280  320
y
  0    [00] [10] [20] [30] [40] [50] [60] [70] [80]
 56    [01] [11] [21] [31] [41] [51] [61] [71] [81]
112    [02] [12] [22] [32] [42] [52] [62] [72] [82]
168    [03] [13] [23] [33] [43] [53] [63] [73] [83]
```

`[cr]` = 第 `c` 列、第 `r` 行。`y` 加上 224 就是同一格的发光遮罩。

### 1.3 三块区域的分工

| 列 | 行 | 用途 |
|---|---|---|
| 0、1 | 0~3 | 躯干（男/女各一套，含跳跃姿）与左右肩 |
| 2~6 | 0~3 | 手臂，按 **身体帧号** 索引 |
| 7 | 0~3 | 前臂，玩家 **挥动武器/道具** 时使用，4 行 = 4 档伸缩 |
| 8 | 0~3 | 后臂，同上 |

### 1.4 帧号 → 格子（手臂）

| 身体帧 | 前臂格 | 后臂格 | | 身体帧 | 前臂格 | 后臂格 |
|---|---|---|---|---|---|---|
| 0 | `(2,0)` | `(2,2)` | | 10 | `(4,1)` | `(4,3)` |
| 1 | `(3,0)` | `(3,2)` | | 11 | `(3,1)` | `(3,3)` |
| 2 | `(4,0)` | `(4,2)` | | 12 | `(3,1)` | `(3,3)` |
| 3 | `(5,0)` | `(5,2)` | | 13 | `(3,1)` | `(3,3)` |
| 4 | `(6,0)` | `(6,2)` | | 14 | `(5,1)` | `(5,3)` |
| 5 | `(2,1)` | `(2,3)` | | 15 | `(6,1)` | `(6,3)` |
| 6 | `(3,1)` | `(3,3)` | | 16 | `(6,1)` | `(6,3)` |
| 7 | `(4,1)` | `(4,3)` | | 17 | `(5,1)` | `(5,3)` |
| 8 | `(4,1)` | `(4,3)` | | 18 | `(3,1)` | `(3,3)` |
| 9 | `(4,1)` | `(4,3)` | | 19 | `(3,1)` | `(3,3)` |

注意 **多个身体帧共用同一格**：原版第 7~10 帧用同一个手臂画法，第 11~13 帧与 18~19 帧共用
`(3,1)`。所以新格式一套盔甲只需要 5 + 5 个手臂姿态，而不是 20 个。

### 1.5 引擎的绘制顺序

把格子贴回一帧时，顺序必须是（同一位置后画的盖前面的）：

1. 后肩 `(1,1)` 男 / `(1,3)` 女
2. 后臂 `(c, r+2)`
3. 躯干 `(0,0)`，第 5 帧用 `(1,0)`；女性用 `(0,2)` / `(1,2)`
4. 前肩 `(0,1)` 男 / `(0,3)` 女
5. 前臂 `(c, r)`

## 4. 一次切完的示例代码

```python
from pathlib import Path

from PIL import Image

ROOT = Path("Terraria/Content/Images")
CELL_W, CELL_H = 40, 56


# --- 头 / 腿：20 帧竖排 --------------------------------------------------
def strip_sheet(path, frames=20):
    sheet = Image.open(path).convert("RGBA")
    return [sheet.crop((0, f * CELL_H, CELL_W, (f + 1) * CELL_H)) for f in range(frames)]


heads = strip_sheet(ROOT / "Armor_Head_1.png")
legs = strip_sheet(ROOT / "Armor_Legs_1.png")

# --- 身体：9 x 4 九宫格 --------------------------------------------------
body = Image.open(ROOT / "Armor/Armor_1.png").convert("RGBA")
cells = {}
for row in range(body.height // CELL_H):
    for col in range(body.width // CELL_W):
        left, upper = col * CELL_W, row * CELL_H
        cells[col, row] = body.crop((left, upper, left + CELL_W, upper + CELL_H))

# 身体帧号 -> 手臂格
FRONT_ARM = {
    0: (2, 0), 1: (3, 0), 2: (4, 0), 3: (5, 0), 4: (6, 0),
    5: (2, 1), 6: (3, 1), 7: (4, 1), 8: (4, 1), 9: (4, 1), 10: (4, 1),
    11: (3, 1), 12: (3, 1), 13: (3, 1), 14: (5, 1), 15: (6, 1),
    16: (6, 1), 17: (5, 1), 18: (3, 1), 19: (3, 1),
}
BACK_ARM = {frame: (col, row + 2) for frame, (col, row) in FRONT_ARM.items()}


def torso_cell(frame, female=False):
    if female:
        return (1, 2) if frame == 5 else (0, 2)
    return (1, 0) if frame == 5 else (0, 0)


# --- 把一格盔甲合成到一帧 40x56 上 ---------------------------------------
def compose(frame, female=False, base=None):
    out = (base or Image.new("RGBA", (CELL_W, CELL_H))).copy()
    for cell in (
        (1, 3) if female else (1, 1),   # 后肩
        BACK_ARM[frame],                # 后臂
        torso_cell(frame, female),      # 躯干
        (0, 3) if female else (0, 1),   # 前肩
        FRONT_ARM[frame],               # 前臂
    ):
        out.alpha_composite(cells[cell])
    return out


compose(0).save("frame0.png")
```

> 用 `alpha_composite`（按 alpha 混合）而不是 `paste`；引擎用的就是普通 alpha 混合，
> 边缘可能带半透明像素。

## 5. 换算成 1× 素材

上面所有坐标除以 2 就是 1×（ArmorHelper 模板所用的尺度）：

| 2×（原版贴图） | 1× |
|---|---|
| 一格 40 × 56 | 20 × 28 |
| 身体 360 × 224 | 180 × 112（9 列 × 4 行） |
| 身体 + 发光 360 × 448 | 180 × 224（9 列 × 8 行） |
| 头 / 腿 40 × 1120 | 20 × 560（20 帧） |

```python
small = body.resize((body.width // 2, body.height // 2), Image.NEAREST)
```

## 6. 用本仓库的工具直接反推

上面这些坐标就是 `armorhelper/layout.py` 里的 `TORSO_CELL`、`FRONT_ARM_CELL`、
`BACK_ARM_CELL` 等常量，工具已经封装好了：

```bash
# 从原版 id 还原出 128x80 的绘制模板
python3 -m armorhelper reverse --images "Terraria/Content/Images" --body 1 -o Copper.png

# 还原全部套装到 <输出目录>/ArmorTemplate/
python3 -m armorhelper reverse --images "Terraria/Content/Images" --all -o templates/

# 按引擎算法渲染任意一张 1.4.4+ 身体贴图，确认自己切得对不对
python3 tools/inspect_armor.py "Terraria/Content/Images/Armor/Armor_1.png" --frames 0,5
```

```python
from armorhelper.reverse import reverse_from_images

result = reverse_from_images("Terraria/Content/Images", body=1, head=1, legs=1)
result.template.save("Copper.png")  # 128 x 80
```
