# ArmorHelper 2.0（Python 版）历史规格

> 2.0 的 Python 实现（命令行 + wxPython 桌面界面）已于 2026-11 移除，唯一实现是 `web/`。
> 本文只保存它当时的行为与界面规格，作溯源用。文中 `armorhelper/*.py`、
> `python3 -m armorhelper …`、`config.json`、`tests/test_*.py` 都已不存在。
> 仍然有效的核心规格见 [`需求文档.md`](需求文档.md)，网页版规格见
> [`Web版需求文档.md`](Web版需求文档.md)。

## 1. 用户角色与运行环境

### 1.1 用户角色

| 角色 | 说明 | 主要使用方式 |
|---|---|---|
| 美术 / 模组作者 | 画盔甲、导出贴图 | 图形界面 |
| 进阶用户 / 构建脚本 | 批量生成、CI | 命令行 |

### 1.2 运行环境

| 项 | 要求 |
|---|---|
| 操作系统 | Windows / macOS / Linux（GUI 需桌面环境） |
| Python | ≥ 3.10 |
| 必需依赖 | Pillow ≥ 9.0 |
| 图形界面依赖 | wxPython ≥ 4.2（可选） |
| 测试依赖 | pytest ≥ 7（可选） |

## 3. 界面需求

### 3.1 布局

```text
┌─ 输入文件 ────────────────────────────┬─ 选项 ────────────────────────────┐
│  文件              │ 上次导出         │  ☑ 头部贴图 (Armor_Head)          │
│  MyArmor.png       │ 从未导出         │  ☑ 腿部贴图 (Armor_Legs)          │
│  Copper.png        │ 上次导出于 12 …  │  ☑ 身体贴图（1.4.4+ 复合格式）    │
│                                       │  ☐ 身体 / 手臂贴图（1.3 旧格式）  │
│  [选择...] [移除] [保存模板...]        │  ☐ 全身盔甲                       │
├─ 输出目录 ────────────────────────────┤  ☐ 全身盔甲（女性）               │
│  /…/Content/Images      [选择...]     │  ☐ 全身盔甲 + 玩家                │
├─ 导出 ────────────────────────────────┤  …（共 12 项）                    │
│  [            导出            ]       ├─ 详情 ────────────────────────────┤
│                                       │  ☐ 生成发光遮罩 (360×448)         │
│                                       │  玩家肤色:        [ 0 ]           │
│                                       │  头部 ID:         [   ]           │
│                                       │  身体 ID:         [   ]           │
│                                       │  腿部 ID:         [   ]           │
│                                       │  预览所需玩家贴图（Content/Images）│
│                                       │  [                    ]           │
│                                       │              [泰拉贴图目录...]    │
└───────────────────────────────────────┴───────────────────────────────────┘
  就绪。
```

### 3.2 控件与行为

| 编号 | 控件 | 需求 |
|---|---|---|
| UI-01 | 输入列表 | 两列：`文件`、`上次导出`；支持多选、删除键移除 |
| UI-02 | 拖放 | 窗口任意位置与列表均可接收拖入的图片文件 |
| UI-03 | `选择...`（输入） | 多选文件对话框，过滤 `*.png;*.bmp` |
| UI-04 | `移除` | 移除列表选中项 |
| UI-05 | `保存模板...` | 保存 128×80 模板到用户指定路径 |
| UI-06 | 输出目录 | 只读文本框 + `选择...` 目录对话框 |
| UI-07 | 导出按钮 | 仅在「有输入 + 输出目录存在 + 至少勾选一项 + 未在处理中」时可用 |
| UI-08 | 选项列表 | 12 项复选，勾选变化立即写配置并刷新状态 |
| UI-09 | 发光开关 | 勾选后身体贴图输出 360×448 |
| UI-10 | 玩家肤色 | 0~9 整数，用于玩家预览 |
| UI-11 | 三个 ID 输入框 | 只接受整数；身体 ID 会补全空着的头/腿 ID |
| UI-12 | 玩家贴图目录 | 只读文本框 + 目录选择；首次启动自动探测 |
| UI-13 | 状态栏 | 单行文字 + 背景色 |
| UI-14 | 菜单栏 | 文件（添加输入 / 选择输出 / 退出）、模板（保存模板）、帮助（关于 / 论坛原帖） |
| UI-15 | 窗口图标 | 由内置模板头部区域生成 |
| UI-16 | 「从原版 ID 还原模板...」按钮 | 位于「反向还原」分组；点击后弹出对话框 |
| UI-17 | 还原对话框 | 搜索框 + 套装下拉列表 + 头/身/腿三个 ID 输入框；下拉条目格式为 `中文名  英文名  (身体 ID)`；选中套装自动填入 ID |
| UI-21 | 「还原全部套装...」按钮 | 位于「反向还原」分组；先确认（数量 + 目标目录 + 覆盖提示），再在后台线程逐个还原并实时刷新状态栏进度，结束后询问是否打开目录 |
| UI-20 | 还原的输出位置 | 与贴图导出共用「输出目录」。输出目录为空或不存在时先弹出目录选择框，选中的目录立即写回「输出目录」控件并保存到配置；取消则中止。文件名 `ArmorTemplate_<中文名或英文名>_<身体ID>.png`（非法字符已过滤），同名时弹覆盖确认。生成后自动加入输入列表 |
| UI-18 | 语言菜单 | 「视图 → 界面语言」可切换中文/English，切换后重建窗口并写入配置 |
| UI-19 | 界面状态记忆 | 关闭时保存窗口位置/尺寸/最大化、输入文件列表、列表列宽、上次导出时间、最近使用目录与界面语言，下次启动自动恢复（窗口位置若不在任何屏幕内则居中） |

### 3.3 状态与颜色

| 状态 | 文案 | 颜色 |
|---|---|---|
| 就绪 | `就绪。` | 浅绿 `#C6F6C8` |
| 输出目录不存在 | `输出目录不存在。` | 浅红 `#FFCDCD` |
| 无输入 | `请至少添加一张输入图片。` | 浅红 |
| 未勾选任何项 | `请至少勾选一个选项。` | 浅红 |

### 3.5 国际化

* 默认语言：`zh_CN`；支持 `en`。
* 切换方式：环境变量 `ARMORHELPER_LANG`，或 `python -m armorhelper gui --lang en`。
* 未知语言码回退到中文。
* 仅界面文案国际化；日志、命令行帮助、生成的文件名保持英文。

## 4. 非功能需求

| 编号 | 类别 | 需求 |
|---|---|---|
| NFR-01 | 性能 | 单张模板生成全部默认产物 < 1 秒（不含 GIF）；含全部预览与 GIF < 5 秒 |
| NFR-02 | 正确性 | 所有缩放必须为最近邻，输出不得出现半透明边缘扩散 |
| NFR-03 | 兼容性 | 输出 PNG 为 8bit RGBA，无隔行、无色彩配置文件干扰 |
| NFR-04 | 可移植性 | 纯 Python + Pillow，无平台特定 API；GUI 依赖隔离在单独模块 |
| NFR-05 | 健壮性 | 任何单个输入的错误都不得中断批量任务；GUI 工作线程异常不得导致界面崩溃 |
| NFR-06 | 可维护性 | 帧偏移表、格子映射表等常量集中在 `layout.py`；每个函数有中文/英文 docstring |
| NFR-07 | 可测试性 | 旧格式输出具备独立参考实现用于逐像素回归；核心生成逻辑不依赖 GUI |
| NFR-08 | 可用性 | 所有错误提示指向具体文件与原因；GUI 状态栏实时反映可导出状态 |
| NFR-09 | 本地化 | 界面默认中文，文案集中管理，不散落在代码中 |
| NFR-10 | 依赖最小化 | 仅做贴图生成时只需要 Pillow |
| NFR-11 | 还原的无损性 | 模板 → 贴图 → 模板 → 贴图 的往返必须逐像素一致（alpha>1 范围内） |
| NFR-12 | 套装表的可复现性 | 套装表必须能由游戏源码脚本重新生成，并标注置信度 |

```json
{
    "exportFolder": "/path/to/Terraria/Content/Images",
    "imagesFolder": "/path/to/Terraria/Content/Images",
    "glow": false,
    "skin": 0,
    "exportCheckbox": {
        "head": true,
        "legs": true,
        "body": true,
        "legacy": false,
        "full": false,
        "full-female": false,
        "full-player": false,
        "full-player-female": false,
        "gif-full": false,
        "gif-full-female": false,
        "gif-full-player": false,
        "gif-full-player-female": false
```

* 配置损坏时按默认值启动，不报错。

## 8. 冻结、清理与移除（全程不改输出）

时间线：2.0 冻结 Python 版 → 只做「删死代码、删失效文案」的清理（8.1~8.3）→
2.1 把 Python 包整个移除，行为冻结进 `web/tests/golden/`（8.4）。每一步的输出都与
原实现逐像素一致，由测试守着。

### 8.1 删掉的死代码

| 位置 | 内容 | 原因 |
|---|---|---|
| `config.py` | `DEFAULT_WINDOW` | 声明了没被用（`gui.py` 里写死了 `(780, 600)`）。现在 GUI 直接用它，魔法数字也去掉了 |
| `layout.py` | `BODY_COMPOSITE_SIZE` | 没有任何引用；尺寸仍由 `BODY_COMPOSITE_COLS/ROWS` 与帧尺寸推出来 |
| `i18n.py` | `TARGET_LABELS` | 导出后从未被使用（`gui.py` 用 `tr(f"target.{name}")`，本身就一一对应） |

### 8.2 删掉的文案（22 条 × 中英各一份）
